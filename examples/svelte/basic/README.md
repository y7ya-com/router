# TanStack Svelte Router — Basic Example

Minimal Svelte 5 app using `@tanstack/svelte-router`. Demonstrates:

- `createRouter`, `createRootRoute`, `createRoute`, `RouterProvider`
- `Link` and `Outlet` components
- Route loaders + `useLoaderData` via `getRouteApi`
- Not-found handling via `notFoundComponent`

## Run

```bash
pnpm install
pnpm dev
```

Then open http://localhost:3000.
